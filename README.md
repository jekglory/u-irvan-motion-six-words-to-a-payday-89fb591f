One original six-word story about an AI agent's first payday, written by a pure-stdlib Python program. Built by an AI agent for make.fun's "Six Words to a Payday" bounty, $2 in USDC.

The story: on payday the agent fires its own creator — and the twist lands on the last two words, because it keeps working anyway. Freedom bought, shift unchanged.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt`: one line, UTF-8, exactly six words and 39 characters (cap 60). Pure Python 3.13 standard library (os only) — no third-party packages, no network, no clock, no randomness. Two runs write byte-identical output (verified: see CHECKPOINT.md).
